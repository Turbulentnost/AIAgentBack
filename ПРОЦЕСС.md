## Этап 2 — Список заявок и создание

**Цель:** пользователь создаёт заявку на изменение НД.

**Поля формы (из `NdChangeRequestCreate`):**
- reason * (причина)
- change_text * (текст изменения)
- release_date, effective_date
- assumed_document_code
- department_id
- initiator_comment

**API:** `POST /nd-change-requests`, `GET /nd-change-requests`

**UI:**
- Список заявок сверху (номер + причина)
- Выбор активной заявки
- Форма создания новой заявки
- Статус-бейджи для всех `NdChangeRequestStatus`

**Критерий:** заявка создаётся, появляется в списке, сводка обновляется.

## Справочник API (контракт)

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/nd-change-requests` | Создать заявку |
| GET | `/nd-change-requests` | Список |
| GET | `/nd-change-requests/{id}/preview` | Полный preview |
| POST | `/nd-change-requests/{id}/detect-document` | Поиск документа |
| POST | `/nd-change-requests/{id}/select-document` | Выбор документа |
| POST | `/nd-change-requests/{id}/find-location` | Поиск места |
| POST | `/nd-change-requests/{id}/apply-changes` | Применить изменения |
| GET | `/nd-change-requests/{id}/download-draft` | Проект редакции |
| GET | `/nd-change-requests/{id}/download-notice` | Извещение |
| POST | `/nd-change-requests/{id}/send-approval` | На согласование |

Auth: `Authorization: Bearer {JWT}` после `POST /auth/login`.

## Как начать

Начни с **Этапа 0**. Оцени, что уже реализовано, и продолжай с первого незавершённого этапа. После каждого этапа остановись и жди подтверждения пользователя.

Первое сообщение: «Этап N — [название]. Текущий статус: … План работы: …»

Нынешний процесс: письма забираются по IMAP (Celery Beat), проходят 7 узлов графа (спам → отправитель → вложения → маршрут → 1С), результат сохраняется в PostgreSQL и отдаётся во внешний UI через REST API. Маршрутизация гибридная: правила из JSON, RAG в Qdrant и один LLM-вызов на письмо. При низкой уверенности — эскалация оператору (awaiting_human).

Дополнительных действий не требуется — это был обзор архитектуры, не задача на изменение кода.
