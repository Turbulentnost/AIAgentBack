# Агент закупок «Авион» — инструкция для менеджеров и руководителя

## Как открыть

1. Войти в платформу AI Agent.
2. В каталоге агентов выбрать **«Агент закупок (Авион)»** (на экране — **«Закупки · Авион»**).
3. После первого анализа данные сохраняются: при следующем входе дашборды и задания подгрузятся автоматически.

---

## Менеджер по закупкам

### Ежедневная работа

1. Откройте агента **«Закупки · Авион»**.
2. Перейдите в блок **«Мои задания»** (или вкладку **«Задания»** на дашборде обеспеченности).
3. Сначала обработайте задания в разделе **«Срочные»** (приоритеты «Срочно» и «Сегодня»), затем — **«На неделю»**.
4. Типы заданий:
   - Отгрузка
   - Логистика МСК
   - Таможня
   - Логистика Ростов
   - Необходимые закупки
5. Выполните действие по заданию и заполните поле **«Результат»** (результат работы).
6. После заполнения система проверит результат и покажет статус: выполнено / частично / не выполнено.
7. При необходимости используйте подсказку ИИ для формулировки результата.

### Завершение смены

1. В конце рабочего дня нажмите **«Завершить смену»**.
2. Укажите причины по незакрытым заданиям.
3. Подтвердите отправку — отчёт уйдёт руководителю на e-mail.

### Что видит менеджер

- Только **свои** задания (по колонке «Ответственный менеджер»).
- Дашборд обеспеченности: изделия, номенклатуры, задания.
- Доску рисков логистики (контрольные точки: загрузка → МСК → таможня → Ростов).
- Блок **«Результаты работы менеджеров»** менеджер **не видит**.

---

## Руководитель

### Контроль после анализа

1. Откройте агента **«Закупки · Авион»** (после того как аналитик провёл анализ Excel).
2. Проверьте **дашборд обеспеченности** — вкладки «Изделия», «Номенклатуры», «Задания»; период: день / неделя / месяц.
3. Просмотрите **доску рисков логистики** — фильтр по уровню риска.
4. Откройте **«Сменное задание»** — полный список заданий по всем менеджерам.
5. Скачайте файл **«сменное_задание_закупки.xlsx»** при необходимости.

### Контроль работы менеджеров

1. На дашборде обеспеченности откройте блок **«Результаты работы менеджеров»**.
2. Смотрите по каждому менеджеру: всего заданий / выполнено / не закрыто.
3. Читайте причины незакрытых задач из отчётов о завершении смены.
4. Отчёты о завершении смены также приходят на e-mail (тема: «Avion: отчёт завершения смены …»).

### Что видит руководитель дополнительно

- Полное **«Сменное задание»** по всем менеджерам (не «Мои задания»).
- Сводку **«Результаты работы менеджеров»**.
- Те же дашборды обеспеченности и логистики, что и у менеджеров.

| Роль | Действие |
|------|----------|
| Менеджер | Открыть агент → «Мои задания» → выполнить → заполнить «Результат» → «Завершить смену» |
| Руководитель | Открыть агент → обеспеченность и риски → «Сменное задание» → «Результаты работы менеджеров» |

## Обратная связь

В правом нижнем углу — виджет **«Обратная связь по агенту закупок Авион»**. Используйте его для замечаний и предложений по работе агента.
