=== Что такое ГОСТ 2.105 ===
ГОСТ 2.105 / 2.102 — спецификация (BOM).

ПРОВЕРИТЬ: разделы BOM; поз./обозн./наим./кол.; позиции ↔ выноски; порядок и нумерация.
НАРУШЕНИЯ: позиция без строки BOM; строка без выноски; дубли/пропуски.

НЮАНСЫ:
Разделы спецификации (порядок): документация → комплексы → сборочные единицы → детали →
стандартные изделия → прочие изделия → материалы → комплекты.
Колонки: поз., обозначение, наименование, кол., примеч. Нумерация позиций сквозная в разделе.
Сборочный чертёж (2.109 п.7): каждая позиция — выноска с номером; номер только на видимых видах/разрезах;
расположение параллельно основной надписи, вне контура. Позиция на виде ↔ строка BOM.
Основной КД для СЕ/комплекса — часто спецификация (2.102 п.5.3). Без дублей и пропусков в нумерации.

ИЗ СТАНДАРТА:
7.3 Номера позиций

7.3.1 На сборочном чертеже все СЧ сборочной единицы нумеруют в соответствии с номерами позиций, указанными в спецификации этой сборочной единицы. Номера позиций наносят на полки линийвыносок, проводимых от изображений СЧ.
7.3.2 Номера позиций указывают на тех изображениях, на которых соответствующие СЧ проецируются как видимые, как правило, на основных видах и заменяющих их разрезах....
5.3  Для комплекса, сборочной единицы и комплекта в качестве основного КД может быть использована спецификация или ЭСК. 
5.4  Для детали в качестве основного КД может быть использован чертеж или ЭМД. 
5.5  Основной КД должен быть явно выделен. Для этого рекомендуется в обозначение КД, выполняющего функцию основного, не включать код вида документа, установленный в таблице 1*.
