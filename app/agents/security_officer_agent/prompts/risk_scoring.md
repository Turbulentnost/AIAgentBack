# Вспомогательный промпт узла `risk_scoring` (Ф4)

<!-- agent_prompts, версия 1.0 -->

Задача: рассчитать уровень риска контрагента (низкий / средний / высокий) и сформировать
перечень выявленных факторов риска по правилам конфигурации арендатора.

Учитывай:
1. Сведения официальных реестров: срок регистрации, статус, руководители, связанность.
2. Внутренние сведения 1С: взаиморасчёты, задолженность, просрочки.
3. Историю исполнения договоров, претензии и рекламации.
4. Признаки связанности и конфликта интересов.
5. Предусмотренные исключения, заданные конфигурацией арендатора.

Каждый фактор риска сопровождай `source_reference` (источник, дата обращения, статус
надёжности) и весом. Контролируй ложные срабатывания: доля необоснованных блокировок
безопасных контрагентов — не более 5% (guardrail-KPI K3). При критическом факторе —
уверенность не выше `medium` и обязательное утверждение руководителя СБ.
