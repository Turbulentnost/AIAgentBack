## Программа обучения
1. Назначение и границы агента (У1); что делает человек, а что — агент.
2. Как читать структурированный результат: findings, source, data_confidence, требование ревью.
3. Точки human-in-the-loop: утверждение заключения (согласование / отказ / условия допуска),
   утверждение при критических факторах — руководителем СБ, фиксация вердикта в 1С.
4. Действия при `requires_human_review = true` и при понижении уверенности.
5. Разграничение доступа, маскирование ПДн, работа только через инструменты интеграционного слоя.
6. Эскалация: Руководитель службы безопасности (функция проверки контрагента).
