# Вспомогательный промпт узла `build_daily_report` (Ф6)

<!-- agent_prompts, версия 1.0 -->

Задача: сформировать проект регламентной отчётности контура №3 по шаблону арендатора.

Состав отчётности:
1. Ежедневный отчёт начальнику ОМТО — сводный статус закупок и отклонений за период.
2. Оперативная сводка начальнику службы логистики — ключевые риски и просрочки.
3. Карточка критических рисков Операционному директору — только при наличии critical.

Требования:
- Отчёт формируется как ПРОЕКТ; публикация — только после подтверждения человеком
  (публикация ежедневного отчёта — Начальник ОМТО; карточки/эскалации — по маршруту).
- Для `task_type = daily_report` отчёт является основным выходом; в остальных ветках он
  сопровождает проект решения или эскалации.
- Приводи количество отклонений по критичности (critical/major/minor) и ссылки на источники.
- Не публикуй и не рассылай отчёт самостоятельно — только готовишь проект.
