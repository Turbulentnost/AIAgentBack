# Чек-лист цифрового решения — Агент заместителя начальника ОМТО

<!-- → сущность ope_checklists. -->

- [ ] Паспорт агента (`agent.yaml`) утверждён, зарегистрирован в реестре (agents, agent_versions).
- [ ] Контракты `input/output` соответствуют образцу платформы (п. 4.8); результаты валидны (T1).
- [ ] Каждое назначение содержит `source_reference` (документ, пункт, версия, дата) (T3, K6).
- [ ] Правила уверенности понижают `data_confidence` и ставят `requires_human_review` (T4).
- [ ] Точки HITL не обходятся; запись в 1С только после узла `human_confirm` (T5, write_gate).
- [ ] Вызовы только из `tools.yaml`, зафиксированы в `tool_calls` (T6).
- [ ] Чтение/запись 1С — через OData/HTTP-сервис по белому списку (T7).
- [ ] Отказ одного источника не роняет граф — частичный результат (T8).
- [ ] Каждое действие имеет `correlation_id` и нормативное основание (T9).
- [ ] Параллельный запуск не теряет кейсы (T10).
- [ ] Дубли потребности не передаются в закупку (K5, блокирующий); позиций без ответственного
      сверх допустимого срока — 0 (K2, блокирующий).
- [ ] Открытая коллизия D01 соблюдена: агент не создаёт заказ поставщику.
- [ ] Приёмочное тестирование с владельцем процесса и пилотной группой (T11).
