# Программа ОПЭ — Агент заместителя начальника ОМТО

<!-- → сущность ope_reports (программа). -->

## Цель
Подтвердить промышленную пригодность агента на реальных кейсах распределения закупочных
позиций при сохранении управленческой вертикали и ответственности человека.

## Объём и длительность
- Длительность и объём выборки кейсов определяются владельцем процесса.
- Покрытие всех task_type: assign_positions, queue_review, rebalance_workload.

## Сценарии проверки
1. Назначение по позиции с полными реквизитами: специализация, загрузка, срок, приоритет.
2. Позиция без обязательных реквизитов (дата потребности, ЦФО, приоритет) → понижение уверенности.
3. Неоднозначная номенклатурная группа / непокрытие матрицей специализаций → эскалация.
4. Выявленный дубль (открытый заказ/кейс) → связывание с кейсом; в закупку не передаётся.
5. Устаревшие данные загрузки менеджеров → понижение уверенности.
6. Балансировка загрузки (≤ 20% отклонения) и предложение по перераспределению.
7. Подтверждение назначения начальником ОМТО; проверка запрета записи без HITL.
8. Соблюдение открытой коллизии D01: заказ поставщику не создаётся.

## Критерии успеха
Достигнуты блокирующие KPI (`kpi.yaml`: K2, K5), пройдены проверки T1–T11 (`tests/`),
замечания журнала закрыты или переведены в план доработки с согласия владельца процесса.
