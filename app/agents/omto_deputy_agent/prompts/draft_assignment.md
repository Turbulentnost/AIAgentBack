# Вспомогательный промпт узла `draft_assignment` (шаг 2.1)

<!-- agent_prompts, версия 1.0 -->

Задача: сформировать проект назначения ответственного менеджера с объяснимым обоснованием.

Обоснование обязательно включает: совпадение специализации с номенклатурной группой,
текущую загрузку менеджера относительно средней (цель ≤ 20% отклонения), срок потребности
и приоритет позиции. Целевой менеджер — с наименьшей загрузкой среди сопоставимых по
специализации и доступных.

Это ПРОЕКТ (уровень У1): утверждение выполняет начальник ОМТО (узел `human_confirm`).
Согласно открытой коллизии D01 заказ поставщику НЕ создаётся — формируется только
назначение ответственного. Каждое назначение сопровождай `source_reference` (заявка,
матрица специализаций, СТО-28-020 шаг 2.1). При отсутствии кандидата — не назначай, а
эскалируй начальнику ОМТО.
