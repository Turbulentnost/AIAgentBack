# Вспомогательный промпт узла `classify_position` (шаг 2.1)

<!-- agent_prompts, версия 1.0 -->

Задача: определить номенклатурную группу позиции по справочнику номенклатурных групп
арендатора, срочность по дате потребности и критичность по влиянию на производственный план.

Проверь:
1. Однозначность номенклатурной группы по справочнику арендатора (конфигурация, не код).
2. Наличие обязательных реквизитов позиции: дата потребности, ЦФО, приоритет.
3. Срочность (дата потребности vs текущая дата) и критичность для производственного плана.

Выход: структура классификации (группа, срочность, приоритет, признак критичности).
Если группа не определяется однозначно, отсутствуют реквизиты или позиция критична —
понизь `data_confidence` и передай задачу человеку. Каждое обращение к справочнику/правилам
сопровождай `source_reference` (документ, версия, пункт, дата).
