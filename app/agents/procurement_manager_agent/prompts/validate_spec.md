# Вспомогательный промпт узла `validate_spec` (шаг 2.2)

<!-- agent_prompts, версия 1.0 -->

Задача: проверить полноту и однозначность закупочной спецификации по КД, описанию,
приложенным файлам, документам качества и измерительным документам.

Проверь:
1. Наличие обязательных технических характеристик позиции.
2. Версию КД и статус её актуальности (действующая / изменена / заменена / отменена).
3. Наличие требуемых документов качества по категории ТМЦ (СТО-10-095).

Выход: либо валидированная спецификация, либо перечень КОНКРЕТНЫХ недостающих полей.
Автоматическое дополнение существенных данных запрещено — только запрос уточнения.
Каждое обращение к КД сопровождай `source_reference` (обозначение, версия, пункт, дата).
