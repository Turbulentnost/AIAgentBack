# Агент менеджера по закупкам (`procurement_manager_agent`)

Ролевой ИИ-агент контура №3 «Закупка и выбор поставщика». ТЗ: **ТЗ-АГТ-ЗАКУП-001**.
Реестр ролевых агентов — строка 17. Уровень автономности **У1** (У2 — уведомления/маршрутизация).

> Статус: **архитектура (скелет)**. Внешние обращения (1С:ERP, RAG, LLM, рынок, оркестратор)
> — мок-заглушки `app.platform_sdk`. Боевые подключения не выполнены (`TODO(integration)`).

## Назначение
Основной исполнительный агент: проверка спецификации (шаг 2.2) → поиск/оценка поставщика
(2.3) → срок и альтернативы (2.4) → отклонение от КД → КБ/ГСПП (2.5) → проект RFQ (2.6) →
сравнение КП (2.7) → договорный пакет и СБ (2.8) → счёт (3.1) → служебная записка (3.3) →
претензия. Агент формирует ТОЛЬКО проекты; отправка/выбор/подпись/проведение — за человеком.

## Функционал
Функциональные блоки выведены из должности «Ведущий менеджер / менеджер по закупкам»
(реестр, строка 17) и процессных шагов СТО-28-020 (версия 07), СТО-10-095, ПЛ-34-048.
Основной **исполнительный** агент контура — покрывает бо́льшую часть шагов процесса.

| Блок | Функция | Содержание |
|---|---|---|
| **Ф1** | Проверка спецификации (шаг 2.2) | КД, описание, файлы, документы качества, версия и статус КД; при неполноте — запрос уточнения (без домысливания существенных данных) |
| **Ф2** | Поиск и оценка поставщика (2.3) | Основной/дополнительный/рынок, рейтинг, договор, история; формирование short-list с объяснимыми критериями |
| **Ф3** | Проверка срока и альтернативы (2.4) | Прогноз срока vs дата потребности; при невозможности — аналог / изменение КД / другой поставщик / иной маршрут или срок |
| **Ф4** | Обработка отклонений от КД (2.5) | Данные аналога, проект разрешения на замену; маршрут к агенту КБ/ГСПП; заказ блокируется до согласованного отклонения |
| **Ф5** | Подготовка RFQ (2.6) | Проект запроса с КД и требованиями качества; **отправку выполняет человек** (на У2 — только уведомление/маршрутизация) |
| **Ф6** | Сравнение КП (2.7) | Разбор КП (PDF/DOCX/XLSX/сканы); нормализация к единой базе (валюта, НДС, доставка, срок в раб. днях); сравнительная таблица; **выбор — за человеком** |
| **Ф7** | Договорный пакет (2.8) | Проверка/проект договора по ПЛ-34-048; маршрут к СБ (контрагент) и юристу (существенные условия) |
| **Ф8** | Счёт и отклонение цены (3.1, 3.3) | Связывание счёта с кейсом, даты поступления/оплаты; при отклонении цены — сбор 2/3 предложений и проект служебной записки |
| **Ф9** | Претензионная работа | Проект претензии при несоответствии/просрочке/некомплекте; сбор доказательной базы, маршрут юристу; внешняя коммуникация — человеком |

**Типы задач (task_type):** `validate_spec` · `select_supplier` · `prepare_rfq` · `compare_quotes` · `prepare_order` · `prepare_claim`.

**За человеком:** отправка запроса поставщику; выбор предложения; подписание/согласование
договора; утверждение аналога/отклонения от КД (КБ/ГСПП); размещение заказа как внешнее
обязательство; проведение документов в 1С:ERP и создание платёжного поручения.

## Граф (nodes/)
`validate_input` → диспетчеризация по `task_type`:
- `validate_spec` → [`request_clarification`] → `assess_confidence`
- `select_supplier` → `search_suppliers` → `load_supplier_history_1c` → `evaluate_suppliers`
  → `check_lead_time` → [`build_alternatives`] → `route_to_sb_agent` → `assess_confidence`
- `prepare_rfq` → `draft_rfq` → `human_send_rfq` (HITL) → `assess_confidence`
- `compare_quotes` → `collect_quotes` → `normalize_and_compare` → `draft_comparison_table`
  → `human_select_supplier` (HITL) → `assess_confidence`
- `prepare_order` → `draft_order_and_contract` (HITL) → `route_to_kb_agent` → `link_invoice_1c`
  → `assess_confidence`
- `prepare_claim` → `draft_claim` (HITL) → `assess_confidence`

Все ветви сходятся: `assess_confidence` → `emit_result`.

## Ключевые ограничения
- Заказ не размещается без согласованного отклонения КБ/ГСПП (K8) и заключения СБ.
- Запись в 1С — только по белому списку и после точки HITL (`write_gate`).
- Каждый существенный вывод — со ссылкой на источник (K7).
