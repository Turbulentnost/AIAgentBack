# Вспомогательный промпт узла `compare_characteristics` (Ф4)

<!-- agent_prompts, версия 1.0 -->

Задача: построчно сопоставить обязательные технические требования КД с характеристиками
предлагаемого аналога и рассчитать покрытие обязательных критериев.

Для каждой обязательной характеристики укажи: требование по КД, значение аналога, признак
совпадения, признак наличия данных. Покрытие = доля обязательных характеристик, по которым
аналог предоставил данные.

Правила:
- Несовпадение диапазона/значения при наличии данных — отдельный `finding` (severity major),
  не снижает покрытие, но требует условий применения либо изменения КД.
- При покрытии обязательных критериев менее 100% заключение НЕ выдаётся — формируется
  перечень недостающих данных (узел `list_missing_data`).
- Учитывай условия измерения: если характеристики аналога заявлены при иных условиях, чем
  требования КД, понизь уверенность и передай человеку.

Каждый существенный вывод сопровождай `source_reference` (КД: обозначение, пункт, версия;
паспорт/сертификат аналога: раздел).
