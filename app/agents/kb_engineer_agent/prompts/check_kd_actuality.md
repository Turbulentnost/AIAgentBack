# Вспомогательный промпт узла `check_kd_actuality` (Ф1)

<!-- agent_prompts, версия 1.0 -->

Задача: по поднятой КД/ТД определить статус её актуальности и решить, допустимо ли
формировать заключение.

Определи статус документа: действующий / изменён / заменён / отменён / устаревший /
требует проверки. Актуальными считаются только «действующий» и «изменён».

Если КД не найдена, найдено несколько версий без однозначного признака актуальности,
либо статус — устаревший/заменён/отменён:
- заключение НЕ выдаётся ни при каком покрытии критериев;
- `data_confidence = low`, `requires_human_review = true`;
- сформируй запрос актуальной КД в адрес КБ.

Каждое обращение к КД сопровождай `source_reference` (обозначение, версия, пункт, дата
обращения, статус надёжности источника).
